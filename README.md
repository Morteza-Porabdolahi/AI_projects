## yolov11.ipynb and yolov8.ipynb
YOLO (you only look once) V8 and V11 detection models trained by a dataset containing images with multiple vehicle types (car, truck, etc.) using [ultralytics](https://ultralytics.com) library.

[Roboflow Vehicles Dataset](https://universe.roboflow.com/roboflow-100/vehicles-q0x2v)
